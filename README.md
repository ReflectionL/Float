# Float — 0.6.2

原生 macOS 多线程工作区。0.5.1 更名为 Float，保留原应用标识、数据目录与 JSON 格式，原工作区继续加载。Swift + SwiftUI + SwiftData，macOS 15+，无第三方依赖。

## 运行

```sh
bash scripts/build-app.sh --open
```

`--universal` 构建 arm64 + x86_64 通用二进制（发版时使用），可与 `--qa`、`--open` 组合。

或在 Finder 中双击 `build/Float.app`。正式版从 [Releases](https://github.com/ReflectionL/Float/releases) 下载 `Float-<版本>.dmg`，打开后把 Float 拖到「Applications」。需要 Swift 6+ 的 Apple Command Line Tools 或 Xcode。脚本直接用 `swiftc` 构建并进行本地 ad-hoc 签名。

图标原稿为 `Resources/AppIcon.png`：纯黑底、四条不同颜色的细线。构建脚本自动通过 `sips` / `iconutil` 生成完整尺寸的 `Resources/AppIcon.icns` 并加入应用包。

0.3.4 在本机 macOS 27 上验证了启动无标题选区、⌘1 仍可聚焦 NOW，以及 NOTE 加载原 NEXT 内容。背景色差修复统一了列与工作区的颜色来源并去掉半透明叠加；尚未在旧版 macOS 实机复核。

0.4 已在独立 QA 窗口验证清单的新增、中文编辑、完成/展开/恢复，以及 NOW 对号在普通显示和正在编辑两种状态下的归档清空。NOW 使用实时数据绑定，并在原生输入结束回调之后执行清空，防止旧文字回填。

0.4.6 已在 QA 窗口验证：事件输入默认隐藏、加号展开聚焦、回车换行、⌘Return 和对号提交后收起、NOTE 中 ⌘Return 结束编辑且不跳转、Escape 收起与旧事件草稿继续编辑。原生换行和输入法 marked text 边界测试通过。

## 工作区

当前界面去掉整列卡片与圆角，线程使用同一系统背景；标题、拖动手柄和更多操作在同一行对齐，状态位于其下。手柄仅在头部悬停、拖动或键盘焦点时绘制，原生拖动视图始终保留。顶部使用紧凑统一工具栏。Now 使用 18 pt 中等字重及主文字色，Note 使用 15 pt 次要文字色，普通历史使用 14 pt 次要文字色，里程碑使用主文字色。历史正文与区域标题左侧对齐，星号移至每条记录右侧：已标记始终显示，未标记在悬停或键盘焦点时显示，辅助功能仍可访问。

0.5.3 将列宽收紧到 340 pt、列间距 10 pt、列内左右留白 20 pt，并压缩区域和历史记录间距。空的 Now / Note 输入区收紧，点击标题或输入区进入编辑后展开；标题、Now、Note 和事件输入在编辑时显示淡色底线。⌘Z / ⇧⌘Z 使用窗口的原生撤销管理器，可撤销和重做 Now 更新/完成、Timeline 提交、里程碑标记、线程排序。撤销事件提交恢复原始草稿并打开输入区；恢复只涉及该操作的字段，不覆盖后来写的 Note。撤销记录保留在本次运行期间，导入工作区后清空；永久删除线程仍通过备份恢复。

0.5.3 验证：8 组核心测试和原生交互测试通过；撤销测试覆盖字段恢复、保留后写的 Note、事件 ID / 时间不变、重做、排序、持久化、导入清空撤销，以及系统自动分组下 Now 更新与完成分别撤销。深色实际窗口已检查收紧的布局、点击空 Now 标题展开和淡色编辑底线；Timeline 提交、⌘Z 恢复草稿并展开、⇧⌘Z 重做通过桌面操作。桌面检查发现 Now 连续操作分组过大的问题并修复，最终修复版已复测：一次 ⌘Z 恢复完成前的 Now，第二次撤销此前更新，重做正常；菜单调整排序后 ⌘Z 恢复原顺序。QA Now 和排序已还原，正式版正常重启，6 个可见线程、4 个已完成线程和用户当天更新的记录正常加载。纯悬停反馈仍未通过工具可靠验证。

本轮构建与原生交互测试通过，包含手柄图形隐藏时的拖动/取消、边缘滚动、输入法 marked text 及换行。2026-10-09 已在 macOS 27 浅色实际窗口检查统一背景、标题对齐、文字层级、默认隐藏的普通星号、里程碑常显、手柄获得焦点时显示，以及 Timeline 加号展开、Return 换行、⌘Return 提交收起和 Note 提交后焦点不跳转。正式版重启后正常加载 6 个可见线程和 4 个已完成线程。工具的指针操作未可靠触发悬停回调，纯悬停显示仍待人工复核；旧版 macOS 尚未实机复核。数据格式、存储目录和编辑快捷键沿用原版。

- 选中的线程整列铺一层浅灰底（圆角，与 Zulip Mac 选中行一致），status 图标显示靛蓝强调色；其余线程保持画布底色，相邻列之间用居中的细分割线隔开，分割线在选中列两侧隐藏。NOW 标题右侧只保留对号按钮。
- 点击输入框时保持当前滚动位置，不再将 NOW / NOTE / Timeline 强制对齐到顶部，也不因切换选中列自动横移。仅显式快捷键导航、新建或恢复线程时将目标列带入视野。
- 极简界面：NOW / NOTE / TIMELINE 无默认提示文字；移除底部状态栏和快捷键提示。顶部只保留窗口标题、数据菜单、已完成和新建图标，悬停可查看用途。线程和工作区使用同一系统背景，自动跟随系统外观；启动时不自动进入标题编辑。
- 首次启动提供三个示例，以后加载本地数据，不重复添加示例。
- 新建、重命名线程，行内编辑 NOW / NOTE。NOTE 用于自由备注，原 NEXT 内容保留；为兼容旧备份，JSON 存储字段仍叫 `next`。
- ACTIVE / WAITING / SLEEPING / DONE 状态切换。
- NOW 草稿自动保存；离开编辑框或在 NOW 内按 ⌘Return 提交，原 NOW 只生成一条时间线记录。无变化或原内容为空时不添加记录。
- NOW 右侧仅在有非空内容时显示对号。点击后将当前内容放入 Timeline 并清空 NOW；重复点击不重复记录。如果存在尚未提交的修改，会先按普通更新规则保留旧 NOW，再归档当前文字。
- 每列顺序为 NOW → NOTE → TIMELINE。Checklist 区域已移除，旧清单自动追加到 NOTE 末尾，使用 `○` / `✓` 保留未完成/已完成状态；空条目忽略。迁移覆盖 DONE 线程，不改变原备注、NOW、历史和时间戳；迁移前备份，保存成功后清除旧清单字段，重启不会重复追加。导入旧 JSON 同样转换。
- **事件输入框中的未提交文字也会保存**，重启、切换列和 DONE/恢复后仍可继续写。输入框默认隐藏，点击标题右侧加号或按 ⇧⌘Return 展开并聚焦；按 ⌘Return 或点击输入框右侧对号提交后收起。Escape 或切换编辑区域会收起输入框并保留草稿，下次展开可继续写。
- Timeline 标题右侧使用添加按钮，移除记录计数；标题、输入框和历史之间的间距缩短，历史条目间距保持不变。时间线倒序显示，只显示时间和内容，移除 Previous NOW 标签；原 NOW 归档记录保留。可标记/取消标记里程碑，标记不改变时间顺序。
- 悬停线程头部后，从标题右侧的三横线手柄拖动；蓝色插入线表示目标位置，松开后调整顺序。在工作区左右边缘拖动时自动横向滚动；Escape 或在工作区外松开可取消。菜单仍提供 Move Left / Move Right。
- DONE 从主工作区移出；工具栏 Done 可查看、恢复为 ACTIVE / SLEEPING，或删除。
- 删除须确认，并先建立可恢复的 JSON 备份。

## 快捷键与编辑边界

| 快捷键 | 操作 |
| --- | --- |
| ⌘N | 新建线程 |
| ⌘1 … ⌘9 | 按当前可见顺序聚焦线程 NOW |
| ⌘[ / ⌘] | 上一个 / 下一个线程 |
| ⌘Return | NOW 中提交更新；Timeline 输入框中提交事件并收起；NOTE / 标题中结束编辑；无编辑时不跳转 |
| Return / ⇧Return | 在 NOW、NOTE、事件输入框中换行；中文候选期间交给输入法处理 |
| ⇧⌘Return | 聚焦事件输入框；已在输入框时提交事件 |
| ⌘S | 立即保存，提交 NOW 草稿 |
| Escape（NOW 内） | 取消本次 NOW 编辑 |
| Escape（拖动时） | 取消排序 |

中文输入法仍有候选文字时，快捷键不会提前提交 NOW/事件或切换列。正常退出及打开文件面板前先结束原生文本编辑，让最终文字进入保存流程。原生列容器拥有自己的键盘焦点，并与工作区按线程 ID 同步，避免排序后快捷键操作错误的列。

## JSON 导入、导出与恢复

从工具栏省略号菜单或 File 菜单进入：

- **Export JSON…**：导出当前完整工作区，包含 DONE、时间线、里程碑、NOW/事件草稿、顺序与时间戳。
- **Import JSON…**：先校验文件，再显示线程列表和数量。取消预览不会修改工作区。
- **Add new threads**（默认）：只添加 ID 尚不存在的线程，保留现有线程版本。重复导入不会创建重复线程。
- **Replace workspace**：用文件内容替换整个工作区。按钮会明确显示 “Back Up & Replace”，替换前备份当前内容。
- **Restore from Backup…**：打开备份文件夹选择 JSON，沿用同一预览和确认流程；恢复过去的完整状态请选 Replace workspace。
- **Open Backups Folder**：在 Finder 中查看备份。

导入遇到损坏文件、未知格式/版本或重复 ID 时会拒绝操作。备份或数据库写入失败时，替换不生效。导出文件是带格式和版本标识的 UTF-8 JSON；日期的编码基准在 `dateEncoding` 字段中明确声明，以保留时间精度。导入/导出大小限制为 20 MB。

0.4.4 继续使用版本 2 的数据快照与 JSON，并兼容版本 1。保留旧 Checklist 解码字段以便迁移旧数据；迁移后的内容存入 NOTE。0.3 及更早版本无法读取版本 2。

## 本地数据与自动备份

```text
~/Library/Application Support/WorkThreadTimeline/
├── workspace.store
├── workspace.store-wal / workspace.store-shm  # SwiftData 可能使用的伴随文件
└── Backups/
    ├── auto-*.json
    └── before-*.json
```

- 自动保存通常在最后一次修改后约 300 ms 执行；窗口失去主焦点和正常退出时立即保存。强制终止/断电仍可能丢失尚未保存的最后一小段输入。
- 成功加载或保存后检查自动备份，最多每 15 分钟写入一次，保留最近 **7 份**。
- 替换导入、删除线程之前单独备份，保留最近 **3 份**。
- 新备份写入并验证成功后才清理旧备份，仅处理应用自己命名的文件。
- 正常保存不显示提示；仅在保存或自动备份失败时显示顶部警告图标，点击可查看错误并重试。普通保存不受自动备份失败影响。替换/删除前的备份失败则取消该操作。
- 数据库打不开、损坏或版本不兼容时显示错误，不会静默覆盖旧数据。错误页面可打开数据文件夹，便于保留原库和查找备份。
- 没有云同步；备份位于同一台电脑，不能覆盖整盘丢失的情况。需要异地留存时可自行保存导出的 JSON。

## 自动更新

发布版启动时会安静地检查 GitHub Releases（最多每 6 小时一次，失败不打扰）；也可以从 **Float → Check for Updates…** 或 **Settings → Updates** 手动检查。发现新版本后，工具栏会出现下载图标，点开可查看说明并 **Install and Restart**。

安装过程：下载 `Float-<版本>.dmg` 及其 `.sha256`，校验 SHA-256，以只读方式挂载后检查代码签名、Bundle ID 和发布标记都与该版本一致，全部通过才在原位置替换应用并重启。正常退出流程会先保存工作区；数据目录、备份和设置不受影响。替换前的旧版会先移到同目录的临时位置，失败时自动还原。

只有发版工作流构建的应用（Info.plist 带 `FloatReleaseTag`）会自动更新；本地 `build-app.sh` 和 QA 版不检查也不替换自己。应用所在目录必须可写，否则提示手动下载。实现参考 Zulip Mac 的更新器。

## 设计语言

界面采用与 Zulip Mac 相同的设计 token（`AppTheme.swift`）：纯白 / 深灰画布，中性色的主、次、三级文字，唯一的靛蓝强调色，四档圆角，三种字重和一组不回弹的动效曲线。区域标题（NOW / NOTE / TIMELINE）使用大写小号字加字距；图标按钮统一为 24 pt 的悬停填充按钮；选中线程的状态图标、拖动插入线、提示按钮使用靛蓝强调色；里程碑星标使用暖色。布局尺寸（列宽 340 pt、间距等）与 0.5.3 保持一致。

## CI 与发版

- **CI**（`.github/workflows/ci.yml`）：每个 PR 和 `main` 上的推送都会在 macOS runner 上构建 Float.app 与 QA 版，运行 `scripts/test.sh`、`scripts/test-native.sh` 和 `scripts/test-updates.sh`，按更新器的方式验证一遍发布包，并检查 README 标题、`CHANGELOG.md` 与 `version.env` 的版本一致。
- **版本号**：唯一来源是 `version.env`（`MARKETING_VERSION` / `BUILD_NUMBER`），构建脚本自动写入 Info.plist。
- **发新版**：运行 `bash scripts/bump-version.sh 0.5.4`，它会更新版本号、构建号、README 标题，并在 `CHANGELOG.md` 顶部加一节待填写的说明。把这次变更随 PR 合入 `main` 后，`.github/workflows/release.yml` 自动测试、构建 arm64 + x86_64 通用版，用 `scripts/package-dmg.sh` 打包 `Float-<版本>.dmg`（带「Applications」快捷方式，附 SHA-256），以 `v<版本>` 为 tag 发布 GitHub Release，说明取自 CHANGELOG 对应小节。同一版本号只会发布一次；`version.env` 未变时不发版。
- 发布包只有 ad-hoc 签名、未经 Apple 公证；首次打开需右键 → 打开，或执行 `xattr -dr com.apple.quarantine /Applications/Float.app`。

## 实现说明

SwiftData 保存一份带版本号的 Codable 工作区快照，适合本应用的小数据量。由于本机 Command Line Tools 不附带 `SwiftDataMacros`，存储记录使用公开 `PersistentModel` 接口显式声明。`ViewState` 别名解决 SDK 同名宏插件缺失问题。

AppKit 只用于线程手柄鼠标追踪、列边界/边缘滚动、原生文件面板及编辑结束边界。界面仍由 SwiftUI 构建，保留 368 pt 列宽与横向线程结构，使用统一系统背景、语义文字色及原生工具栏控件。

本轮没有增加 Scratch、搜索或视觉精修。
