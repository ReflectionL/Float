# App icon

Created with the built-in image_gen tool. The user requested a pure black or white background with a few thin lines in different colors. This replaces the rejected dimensional slider icon.

## Final prompt

Create a completely redesigned macOS app icon, an extremely minimalist flat graphic. Square canvas, 1024x1024. Solid pure black (#000000) rounded square tile centered with standard macOS icon margins, genuinely transparent outside the rounded tile. On the black tile ONLY four very thin, perfectly straight vertical colored lines, evenly spaced horizontally as four independent work timelines. Lines have elegantly rounded caps and modestly different lengths with a balanced staggered arrangement centered optically. Each line is one uniform solid distinct color: soft blue, muted lavender, warm coral, and mint green. Line thickness around 9px at 1024 resolution; longest line about 460px, shortest about 280px; spacing about 95px. Huge amounts of clean black negative space. Sophisticated restrained flat vector-like design, precise geometry, calm and understated. Strictly NO circles or nodes, NO knobs or sliders, NO gradients, NO shadows, NO highlights, NO texture, NO bevel, NO 3D, NO glass, NO border, NO text, NO letters, NO additional marks, NO mockup, NO checkerboard background. Pure black background and only a few different-colored fine lines. Output the single finished icon artwork.

## Assets

- `AppIcon.png`: generated master artwork, preserved at its original resolution.
- `AppIcon.icns`: macOS icon, including 16 / 32 / 128 / 256 / 512 point representations at 1x and 2x, generated by `scripts/build-icon.sh`.
